# 0204 — Historias de usuario de la biblioteca

## 1. Historias de usuario

### HU01 — Consultar disponibilidad

Como socio, quiero consultar los ejemplares disponibles de un libro
para saber si puedo solicitar su préstamo.

### HU02 — Registrar un libro

Como bibliotecario, quiero registrar un libro con título, autor, ISBN
y ejemplares disponibles para incorporarlo al catálogo.

### HU03 — Desactivar el acceso de un bibliotecario

Como administrador del sistema, quiero desactivar la cuenta de un
bibliotecario para impedir que siga accediendo cuando deje de trabajar
en la biblioteca.

Decisión de alcance:
La tercera historia incorpora la gestión de cuentas como una ampliación
del sistema para cubrir el rol de administrador solicitado.

## 2. Comprobación INVEST

| Criterio | HU01 | HU02 | HU03 |
|---|---|---|---|
| Independiente | Puede entregarse con un catálogo de prueba, sin implementar préstamos. | Puede entregarse sin implementar préstamos ni devoluciones. | Puede entregarse sobre cuentas existentes, sin implementar su borrado. |
| Negociable | Se puede acordar cómo buscar y mostrar la disponibilidad. | Se puede acordar el formulario y sus validaciones. | Se puede acordar la forma de localizar la cuenta y confirmar la acción. |
| Valiosa | Ayuda al socio a saber si hay ejemplares. | Permite ampliar el catálogo. | Permite retirar accesos que ya no corresponden. |
| Estimable | Se limita a consultar y mostrar disponibilidad. | Los datos que se deben registrar están definidos. | La acción se limita a cambiar el estado de una cuenta y bloquear el acceso. |
| Pequeña | No incluye reservas ni solicitudes de préstamo. | No incluye importaciones masivas ni modificación de libros. | No incluye borrar cuentas ni gestionar todos los permisos. |
| Testeable | Se puede comprobar con libros con y sin ejemplares. | Se puede comprobar con datos válidos e inválidos. | Se puede comprobar que una cuenta desactivada no puede acceder. |

Estas historias tienen un alcance concreto y no necesitan reformularse
para este ejercicio. Sus dependencias técnicas deben tenerse en cuenta
al planificar su implementación.

## 3. Criterios de aceptación de HU02

### Criterio 1 — Registro correcto

Dado que el bibliotecario tiene permiso para registrar libros y el ISBN
no está registrado,
cuando introduce título, autor, un ISBN válido y tres ejemplares,
entonces el libro aparece en el catálogo con esos datos y tres
ejemplares disponibles.

### Criterio 2 — Número de ejemplares inválido

Dado que el bibliotecario está registrando un libro,
cuando introduce un número negativo de ejemplares,
entonces el sistema rechaza el registro, explica el error y no añade
el libro al catálogo.

### Criterio 3 — ISBN duplicado

Dado que ya existe un libro registrado con un determinado ISBN,
cuando el bibliotecario intenta registrar otro con ese mismo ISBN,
entonces el sistema rechaza el registro duplicado e informa del motivo.

Decisión de diseño:
Cada ISBN identifica una única entrada del catálogo. Los ejemplares
adicionales de esa edición se gestionarían mediante otra operación.
